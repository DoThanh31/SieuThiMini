# Tổng quan dự án: SieuThiMini

Web quản lý siêu thị nhỏ, xây bằng **ASP.NET Core MVC (.NET 8+)**, EF Core, **SQL Server**, Bootstrap 5.

## Tài liệu bắt buộc đọc trước khi làm việc
- Kế hoạch và yêu cầu: @../../docs/plan.md
- Thiết kế kiến trúc và dữ liệu: @../../docs/architecture.md
- Tiến độ các module: @../../docs/progress.md
- Cài đặt SQL Server và chuỗi kết nối: @../../docs/database-setup.md

## Ngôn ngữ
- Trao đổi với tôi bằng **tiếng Việt**.
- Tên class, method, biến, thư mục viết bằng **tiếng Anh**.
- Nhãn giao diện (View), thông báo lỗi cho người dùng viết bằng **tiếng Việt**.

## Skill nên dùng
- Lập kế hoạch tính năng mới: `brainstorming`
- Thiết kế cấu trúc, entity, tầng: `dotnet-architect`
- Viết và review code C#: `csharp-pro`
- Service, EF Core, DI, test, xử lý lỗi: `dotnet-backend-patterns`

## Phạm vi
- Chỉ làm đúng module tôi yêu cầu trong lượt này. Không tự thêm tính năng ngoài kế hoạch.
- Chưa chắc yêu cầu thì hỏi lại, đừng đoán.
